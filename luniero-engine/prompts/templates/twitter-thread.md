# Twitter Thread Template

## Structure
1. **Tweet 1 (Hook)**: Grab attention - bold claim, question, or promise
2. **Tweet 2-N (Body)**: One idea per tweet, build on the previous
3. **Final Tweet (CTA)**: Summarize + call to action (follow, retweet, reply)

## Guidelines
- Each tweet: max 280 characters
- Thread length: 5-12 tweets
- Number tweets (1/, 2/, etc.)
- Use line breaks within tweets
- Include relevant emojis
- First tweet should make people want to read more
- Last tweet should reference the first
